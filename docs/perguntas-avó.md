# Perguntas da Avó (314)

> Status: **rascunho 1** (2026-11-07). Gerado a partir de `src/lib/lvh/perguntas.ts`, a mesma fonte do site. Estrutura em [banco-de-perguntas.md](banco-de-perguntas.md).
>
> Quem pergunta é o neto ou a neta que vai receber o livro. Aqui o texto aparece como se fosse para um neto, filho do seu filho: para uma neta, "pequeno" vira "pequena"; se o neto é filho da sua filha, "o meu pai" vira "a minha mãe" (e "ele" vira "ela").
>
> - **[P]**: cita "meu avô". O app vai trocar o texto ou esconder a pergunta quando não se aplicar.
> - **[G]**: só faz sentido quando o filho veio de uma gravidez.
> - *(opcional)*: tema difícil, e o app deixa claro que dá para pular.
> - *(só da avó)*: pergunta que a Mãe não tem. *(adaptada)*: o texto mudou além do gênero.
